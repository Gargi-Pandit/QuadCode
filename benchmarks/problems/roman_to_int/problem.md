# Roman numerals to integers

Write a Python function `roman_to_int(s: str) -> int` that converts a valid Roman numeral to an integer.

- Symbols: I=1, V=5, X=10, L=50, C=100, D=500, M=1000, with the standard subtractive forms IV, IX, XL, XC, CD, CM.
- The input is always a valid, upper-case numeral for a value from 1 to 3999.
