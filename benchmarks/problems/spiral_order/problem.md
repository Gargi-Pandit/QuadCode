# Spiral matrix order

Write a Python function `spiral_order(matrix: list[list[int]]) -> list[int]` that returns the elements of a rectangular matrix in clockwise spiral order, starting at the top-left corner and going right first.

- The matrix may have zero rows (`[]`) or rows of length zero (`[[]]`); return `[]` then.
- The matrix need not be square. Up to 300 x 300.
