# Two Sum (indices)

Write a Python function two_sum(nums: list[int], target: int) -> list[int] that returns the indices [i, j] with i < j such that nums[i] + nums[j] == target, using the first such pair found when scanning j from left to right. Return [] if no pair exists. Inputs may contain up to 10^5 integers, including negatives and duplicates.
